# AI-Powered Smart Glasses for Visually Impaired People

## Project Overview

This project aims to develop an **offline AI system combining Machine Learning (ML) and Large Language Models (LLMs)** to assist visually impaired people in their daily lives.

The system will use external hardware components attached to a pair of glasses to perceive the surrounding environment, detect nearby obstacles, identify objects, and provide real-time audio guidance to the user.

## How It Works

- **Continuous Image Capture:** A camera attached to the glasses will continuously capture images of the user's surroundings.
- **Obstacle Detection:** An ultrasonic sensor will detect nearby obstacles and measure the distance between the user and the objects.
- **Object Recognition:** Machine Learning and computer vision techniques will identify objects in the environment.
- **Distance Estimation:** The system will combine sensor readings and visual information to estimate how far objects are from the user.
- **AI-Powered Voice Guidance:** An offline LLM will process relevant environmental information and generate simple, understandable instructions to guide the user.
- **Bluetooth Connectivity:** A Bluetooth-enabled device will transmit audio instructions to the user through earphones or a compatible audio device.

## Hardware Components

The external components will be integrated into or attached to the glasses to create a compact, wearable assistance system.

## Current Status

🚧 **Work in Progress**

The project is currently under development. The goal is to build an efficient, lightweight, and reliable offline AI assistant that can help visually impaired people navigate their surroundings more independently.
